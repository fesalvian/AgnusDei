# ✝️ Agnus Dei

**Agnus Dei** é um site católico responsivo que tem como missão aproximar as pessoas de Deus através da fé, da oração e do conhecimento.

🌐 Acesse em: [www.agnusdei.site](https://www.agnusdei.site)

---

## ✨ Funcionalidades

- 🔍 Página “Mais Sobre” com personagens e santos renderizados dinamicamente
- 📜 Páginas dedicadas a Jesus, Maria e orações
- 📰 Notícias católicas em tempo real via RSS
- 📱 Layout totalmente responsivo e adaptado para dispositivos móveis

---

## 🛠️ Tecnologias Utilizadas

### Frontend:
- HTML5, CSS3, JavaScript

### Backend:
- Python 3.12
- Flask + Gunicorn
- MySQL (Railway)
- Biblioteca `requests` para integração com RSS

### Hospedagem e Infraestrutura:
- Railway (backend + banco de dados)
- Hostinger (domínio `agnusdei.site`)
- Certificado SSL automático (HTTPS)
